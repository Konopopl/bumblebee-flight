# Bumblebee Flight

Модель пространственного полёта шмеля и стабилизация при боковом порыве с
задержанными измерениями. В репозитории находятся аэродинамика, кинематика
крыльев, интегратор, регулятор, расчёт показателей и построение графиков и видео.

## Установка

Рекомендуется Python 3.13. Для видео нужны дополнительные зависимости:

```console
python -m venv .venv
python -m pip install -e ".[dev,video]"
```

Перед установкой активируйте окружение: `.venv\Scripts\activate` в Windows
или `source .venv/bin/activate` в Linux и macOS. Для численной регрессии
используется окружение из `requirements-tested.txt`.

## Расчёты

Сравнение задержек 0, 20, 50 и 100 мс для направлений порыва `+y` и `-y`:

```console
bumblebee-flight simulate --output results/delays
bumblebee-flight plot --data results/delays
bumblebee-flight video --data results/delays --delay 20 --view top
bumblebee-flight video --data results/delays --delay 50 --view perspective
```

Первый запуск компилирует аэродинамику. Повторные расчёты в том же процессе
используют скомпилированные функции. Графики сохраняются в PNG и PDF;
координаты, скорости, три угла Эйлера, ошибка скорости, проекции траекторий и
пять параметров управления строятся из одних и тех же массивов.

Для изменения силы порыва и направления:

```console
bumblebee-flight sweep --betas 0.5 0.6 0.79 1 2 3 --delays 20 --output results/forces
bumblebee-flight simulate --directions plus_x minus_x plus_y minus_y plus_z minus_z --delays 20 --beta 0.79 --output results/directions
```

Задержка и горизонт предиктора задаются отдельно. По умолчанию горизонт равен
задержке; `--predictor-steps 0` отключает прогноз состояния. Один шаг равен 5 мс.
Например, исследование горизонта 30 шагов при задержке 100 мс:

```console
bumblebee-flight simulate --delays 100 --predictor-steps 30 --output results/horizon30
bumblebee-flight trim
```

Увеличение силы или изменение горизонта может приводить к потере устойчивости.
Наличие выходного файла само по себе не означает успешной стабилизации.

## Постановка

Масса тела равна 0.418 г, частота взмахов 123 Гц. Аэродинамические силы
усредняются за взмах по 20 временным отсчётам и 100 сечениям крыла. Шаг RK4
составляет 0.005 с, продолжительность основной серии 10 с. Начальное состояние
соответствует равномерному полёту со скоростью `(0.5, 0, 0)` м/с на высоте 0.5 м.

Порыв задаётся внешней силой `F = beta * m * g * d` в мировых координатах,
где `beta` — безразмерная сила относительно веса, `m` — масса, `g = 9.8 м/с²`,
`d` — единичный вектор направления. Сила действует только при `2 < x < 2.05 м`.
При `beta = 0.79` её модуль равен 3.236156 мН. Скорость воздуха в этой серии
не меняется, дополнительный момент от порыва не вводится.

Контроллер получает состояние с транспортной задержкой. Предиктор переносит
его вперёд с помощью локальной линейной модели и истории применённых команд.
LQR регулирует скорости и ориентацию; внешний контур формирует ограниченные
задания боковой и вертикальной скоростей по отклонениям `y` и `z`.
Команды ограничиваются и сглаживаются. Дополнительной транспортной задержки
крыльев нет. Координата `x` не регулируется.

Во всех четырёх случаях используется одна настройка регулятора. Случай 0 мс
означает этот же закон с текущими измерениями и нулевым горизонтом.
Он отличается от прежнего регулятора с переменным усилением.

Прежний закон сохранён отдельным вариантом `scheduled` с исходной
линеаризацией и усилением 0.07…0.14. Для его расчёта без задержки:

```console
bumblebee-flight simulate --controller scheduled --delays 0 --output results/scheduled
```

Этот вариант не компенсирует задержку измерений. Сравнивать влияние самой
задержки следует при фиксированном законе `predictor`.

Подробное описание переменных, матриц и ограничений приведено в
[docs/model.md](docs/model.md).

## Результаты И Проверка

Каждая серия записывает `results.npz`, `config.json` и `metrics.csv`.
В таблице сохраняются знаки экстремального и конечного смещений.
Стабилизация скорости определяется по условию
`||v - v_target||₂ < 0.03 м/с` после выхода из порыва, которое должно
выполняться до конца записи с оставшимся интервалом не менее 1 с.
Это критерий скорости; он не гарантирует возврат координат к исходным значениям.

```console
pytest -m "not slow"
pytest -m slow --regression-output results/delays
ruff check .
```

Регрессионные тесты сравнивают все восемь заново рассчитанных траекторий
из указанного каталога с выборкой ранее сохранённых расчётов.
Видеосцена использует координаты в метрах и длину тела 2.5 см;
масштаб одинаков для разных задержек. Изображение тела условное, движения
крыльев внутри взмаха в видео не воспроизводятся.

## Источники

Аэродинамическое ядро перенесено из исследовательского проекта
`bumblebee-ai-flight` группы Applied RL Control. Исходные коэффициенты
аэродинамической модели и параметры крыла сохранены.
Финальный регулятор и единая серия задержек основаны на рабочей версии
`delay100_model.py`. Сведения о переносе и ограничениях модели:
[docs/provenance.md](docs/provenance.md).
