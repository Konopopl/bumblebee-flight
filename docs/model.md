# Модель И Регулятор

## Состояние

Полный вектор состоит из 18 компонент:

```text
[x, y, z, qw, qx, qy, qz, vx, vy, vz, p, q, r,
 a1_phi, a0_phi, a0_alpha, delta_a1_R, delta_a1_L]
```

| Компоненты | Смысл | Единицы |
|---|---|---|
| `x, y, z` | Координаты центра тела в мировой системе; `z` направлена вверх | м |
| `qw, qx, qy, qz` | Кватернион ориентации тела относительно мировой системы | безразмерные |
| `vx, vy, vz` | Скорость центра тела в мировой системе | м/с |
| `p, q, r` | Угловые скорости вокруг осей тела | рад/с |
| `a1_phi` | Базовая амплитуда первой косинусной гармоники угла взмаха | град |
| `a0_phi` | Нулевой коэффициент Фурье угла взмаха | град |
| `a0_alpha` | Нулевой коэффициент Фурье угла поворота профиля | град |
| `delta_a1_R, delta_a1_L` | Добавки к первой гармонике правого и левого крыла | град |

Интегрируются первые 13 компонент. Последние пять хранят фактически
применённую команду. Кватернион нормируется после каждого шага RK4.
В графиках он преобразуется в крен, тангаж и рыскание, выраженные в градусах.
Из-за принятой в исходной геометрии системы тела направление головы в
визуализации соответствует локальной оси `+z`.

Постоянный член ряда для взмаха равен `a0_phi / 2`; для поворота профиля
он равен `-a0_alpha / 2`. Реальные первые гармоники крыльев вычисляются как
`clip(a1_phi + delta_a1_R/L, 0, 88)`.

## Локальная Модель

Регулятор использует ошибку

```text
e = [dy, dz, dvx, dvy, dvz, roll, pitch - pitch_trim, yaw, p, q, r]
```

Здесь `dy, dz` — отклонения координат от номинальных, `dvx, dvy, dvz` —
отклонения скоростей. Углы и угловые скорости в этом векторе переводятся в
градусы и град/с. Угловые ошибки приводятся к диапазону `[-180, 180)`.

Непрерывная модель имеет вид `de/dt = A e + B du`, где `du = u - u_trim`
— отклонение команды. Матрицы `A` размера 11×11 и `B` размера 11×5
вычисляются центральными разностями уравнений нелинейной динамики около
номинального состояния. Приращения координат и скоростей равны 0.001 в
соответствующих единицах, углов и угловых скоростей — 0.2°, управлений — 0.5°.
Возмущение при линеаризации выключено.

Дискретная модель получается для удерживаемой команды:

```text
expm(dt * [[A, B], [0, 0]]) = [[Ad, Bd], [0, I]]
e_next = Ad @ e + Bd @ du
```

`dt` — шаг расчёта, `expm` — матричная экспонента, `Ad` и `Bd` — матрицы
дискретного перехода и управления. Все вычисления выполняются в float64.

## Предиктор

При задержке `N` шагов в момент `k` доступны измерение `e[k-N]` и команды,
применённые после этого измерения. Оценка текущей ошибки вычисляется по формуле

```text
e_hat[k] = Ad^N @ e[k-N]
           + sum(Ad^(N-1-i) @ Bd @ du[k-N+i], i=0,...,N-1)
```

`e_hat[k]` — оценка ошибки в текущий момент; `i` — индекс команды в истории.
Сила порыва и истинное текущее состояние предиктору не передаются. До начала
записи измерительный буфер заполнен номинальным состоянием.

Горизонт `H` отсчитывается от времени задержанного измерения. При `H=N`
оценивается настоящее состояние, при `H<N` остаётся запаздывание, при `H>N`
оценивается будущее с удержанием последней известной команды.
Эти режимы следует различать при сравнении результатов.

## Управление

Внешний контур задаёт

```text
vy_target = clip(-ky * dy_hat, -vy_limit, vy_limit)
vz_target = clip(-kz * dz_hat, -vz_limit, vz_limit)
v_command += (1 - exp(-dt / tau)) * (v_target - v_command)
```

`dy_hat, dz_hat` — предсказанные смещения; `ky=0.15 с⁻¹`, `kz=1 с⁻¹` —
коэффициенты возврата координат. `vy_limit=0.06 м/с`, `vz_limit=0.12 м/с`
ограничивают задания. `tau_y=0.45 с`, `tau_z=0.40 с` — постоянные времени
фильтров. `v_command` — сглаженное задание соответствующей скорости.

Внутренний LQR использует девять последних компонент ошибки. Из ошибок
боковой и вертикальной скоростей вычитаются сглаженные задания:

```text
Q = diag(8, 30, 16000, 12, 4, 12, 0.8, 0.08, 0.8)
R = diag(0.08, 0.08, 0.10, 0.20, 0.20)
A_inner.T @ P + P @ A_inner
    - P @ B_inner @ inv(R) @ B_inner.T @ P + Q = 0
K = solve(R, B_inner.T @ P)
u_raw = u_trim - gain * K @ e_inner
```

`A_inner=A[2:,2:]`, `B_inner=B[2:]` — модель скоростей и ориентации;
`Q` и `R` — веса ошибки и управления; `P` — решение непрерывного уравнения
Риккати; `K` — матрица обратной связи размера 5×9; `gain=0.0125` —
дополнительный скалярный коэффициент усиления. Он одинаков во всех случаях
и не увеличивается автоматически во время порыва.

Отклонения команды от номинала ограничены `[4,15,8,8,8]°`. Затем применяется
фильтр с `tau_control=0.04 с`, абсолютные пределы
`[0,0,-88,-40,-40]…[88,88,88,40,40]°` и предел приращения
`[0.5,5,1,1,1]°` за шаг. История предиктора хранит команду после всех этих
ограничений.

В основной серии `N=H=0,4,10,20`, что соответствует задержкам 0,20,50,100 мс.
Параметры регулятора вынесены в `ControllerConfig`, параметры эксперимента —
в `SimulationConfig`; полный набор записывается рядом с каждым расчётом.
