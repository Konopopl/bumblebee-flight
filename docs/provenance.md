# Перенос Кода

Исходное аэродинамическое ядро: исследовательский репозиторий
`https://gitlab.appliedai.tech/applied-rl-control/bumblebee-ai-flight.git`,
ветка `PDCexp`, базовый коммит `bf8760602ab3853674cabb9a4c49b1d8cc4080c8`
и рабочие дополнения к пяти параметрической модели.
Коэффициенты CFD/DACE, геометрия крыла, коэффициенты Фурье и правила
усреднения перенесены из этой версии.

Финальный регулятор перенесён из `delay100_model.py` основной рабочей серии
задержек. Сохранённый номинальный режим получен решением задачи равномерного
полёта для 20 отсчётов за взмах. Команда `bumblebee-flight trim` находит
допустимый номинальный режим, который может немного отличаться от эталонного:
три условия решаются для четырёх неизвестных. В основной серии используется
сохранённый эталонный вектор состояния.

Дубли папок, пробные настройки, журналы обучения, ноутбуки с сохранённым
выводом и материалы статьи не являются зависимостями этого пакета.
Старые исходники и результаты остаются в первоначальных рабочих каталогах.

## Ограничения Исходной Физики

Перенос сохраняет численную постановку прежних результатов. Для её
интерпретации существенны следующие допущения:

При переносе добавлена численная защита расчёта силы корпуса при нулевой
скорости: безопасный знаменатель и ограничение аргумента `arccos`.
Формулы на штатных режимах сохранены и проверены по эталонной серии.

- Тензор инерции по умолчанию изотропный: `J = 1.2661670289e-8 * I кг·м²`.
  Это приближение, а не измеренные три главных момента инерции.
- Модель сил крыла использует коэффициенты последнего сечения при
  интегрировании суммарной силы; момент использует локальные коэффициенты.
- Момент корпуса формируется из мировой силы и затем суммируется с
  телесными моментами крыльев. Согласованность этого преобразования
  требует отдельной проверки перед изменением физической постановки.
- Возмущение представляет внешнюю силу, а не измеренный профиль скорости
  воздушного потока из физического эксперимента.
- Проверка ветрового окна выполняется на каждой стадии RK4.
  Сохранённый `wind_active` отмечает положение после шага, а не интеграл
  силы за весь шаг. Для интервала порыва используются интерполированные
  пересечения его границ.
- Пространственный порыв может включаться повторно при обратном движении
  через окно. Столкновение с землёй не моделируется.

Эти допущения не следует скрывать при сравнении расчёта с экспериментом.
Исправление аэродинамических формул потребует новой серии расчётов и нового
номинального режима; текущие эталонные результаты относятся к прежней модели.
